# realheart

让 agent 记住**自己此刻是什么状态**、**没做完什么**，并且在下一轮开口之前把这件事带上。

装它只要一条命令。不装它，你的 agent 也是一个能用的 agent —— 只是每轮都会忘记上一轮发生了什么。

---

## 它解决什么

大部分 agent 每一轮都是新的。

你说过的事、它想过什么、昨天没弄完什么 —— 下一轮就没了。所以你看到的是：它答得很好，但**不连续**。

realheart 做三件事：

1. **让它能记自己的状态**，而且**必须指得出来处** —— 写心情要带一个事件 id；指不出来就写不进去。
2. **每轮把这状态注入回去** —— 它开口之前，那几行已经在上下文里了。
3. **留一本账** —— 你能查、它也能查。没有账的"记忆"就是编的。

有三条规矩，全是机制，不是嘱咐：

| 规矩 | 怎么实现的 |
|---|---|
| 心情必须有来处 | 写心情要带事件 id，指不出来就拒 |
| 改动必须有账 | 谁动了哪一层、为什么、怎么退，她自己查得到 |
| 她自己能停 | 一个工具 `rh_control`，不用等谁记得去按 |

## 装

```bash
npx realheart install --profile <profile>
```

一条命令。它做五件：

1. 装包（`dsh plugin add`）
2. 把包名写进 `dsh.profile.bundles` —— **漏了这步，装了等于没装**（没报错，也没反应）
3. 自检 `@deepseek-ai/schemastery`（pnpm 不装 peer 依赖），缺就补
4. 铺一份用法说明到 `<profile>/skills/realheart/SKILL.md` —— **那是写给你的 agent 的，不是给你的**
5. 铺排程文件到 `~/.dsh/realheart/schedule/` —— 不装也能用，只是它不会自己动

不放心就加 `--dry-run`：一个字节都不写，但会把每一步打出来。

**装完重启 dsh。** 然后：

```bash
npx realheart doctor
```

## 第一次用（三件，一分钟）

1. **跟它说一句「你现在什么感觉」** —— 它应该会调 `rh_mood` 记一笔。
   这一步验的是**通路通不通**，不是效果好不好。
2. **看观测页那本心情账** —— 记完就有了。
3. **第三天再看「她用没用这些」那块** —— 九项里用上几项、空着哪几项。

这三件在观测页首页也会出现一次，有数据之后就自动消失。

**第三天该看什么（这三条比任何配置项都重要）：**

- 它主动做过一件**没人让它做、也不是任务产物**的事
- 它**拒绝过一次**，而且理由是它自己的
- 隔几天**接着做同一件事**

**占一条就没白装。一条都不占，问题多半不在这个插件，在人格那一层。**

## 它到底注入了什么

每轮开口之前，往上下文里加几段（没有内容的段不会出现）：

```
【你现在的状态】           ← 它的心情，带浓度和来处
【这种状态下的你】         ← 它自己写的「这种状态下怎么说话」
【你手上有件没干完的事】
【没完的事】
【你自己做过的一个判断】   ← 它以前拒绝过什么、为什么
【你断言过的事】           ← 它说过会成真/会过时的事，还没被推翻
【这几天】                 ← 只是数：记了几条心情、手上有几件事
```

每段都带一句边界：

> （知道就行，不必说出来 —— 它们不是你聊天的素材，只影响你说话的样子，不是你的话。）

**这句不是客套。** 我们做过五组对照实验：同一句话、同一个人格，只换注入——

| 注入 | 它的回复 |
|---|---|
| 不给状态 | 不提，专心陪对方 |
| 给状态 | **大段复述自己**：「我今天也有点闷，早上看到……」 |
| 把话说更重 | 复述得更起劲 |
| 只给两个词 | 还是带一句「我身上也有点凉」 |
| **加那句禁令** | **一个字都没提** |

所以：**没有这句禁令，状态就会被当成台词念出来。** 它不是防御性写作，是唯一验过的开关。

## 十一个工具

| 工具 | 干什么 |
|---|---|
| `rh_mood` | 记「此刻我是什么状态」。**变了才记**，不是每轮 |
| `rh_style` | 记「这种状态下我怎么说话」 |
| `rh_pending` | 没完的事：加 / 勾掉 / **拒绝（要写理由）** / 删 |
| `rh_claim` | 断言一件会过时的事实 |
| `rh_work` | 手上正在做的东西 |
| `rh_view` | 对一件事的看法 |
| `rh_admit` | 认错 |
| `rh_control` | 自己按开关（暂停 / 先等一会儿 / 收尾） |
| `rh_changes` | 查别人动过它什么 |
| `rh_capabilities` | 外部能力：看有哪些、加一条、改、导出配方 |
| `rh_call` | 按配方真调一次：对话 / 识图 / 生图 / 生视频 / 任意 HTTP |

**它们不是必须都用。** 装了之后观测页会有一块「她用没用这些」，空着哪几项一目了然。
空着不等于坏，但值得问一句：**删掉它，它的行为会变差吗？不会就是装饰。**

用不上的可以在配置里关掉（`toolsOff`）—— 关掉的**压根不注册**，不是注册了再拦。

## 观测页

一个本地网页（默认 `127.0.0.1:8098`，口令在 `~/.dsh/realheart/runtime/config.json`）。

**只在这里能开，不在公网上。**

里面能看到：它的心情账、它主动说过的话、它醒过几次、十一个工具用了哪几项、
它的作品、这一周说了多少话、每条消息的原始记录、外部能力那一栏（每条能点「测一次」真跑）。

改配置也在那儿，**按功能分成九个区**：插件 / 注入 / 短唤醒 / 自由时间 / 提示词 / 外部能力 /
观测页 / 路径与账本 / 边界与工具，一共 60 项。每项后面挂一个来源小标 ——
**面板 / 设置页 / 默认**，一眼看出这个值是谁给的（这两处都能改，`config.user.json` 优先）。

## 设置页

观测页是只读的；真要改配置，dsh 自己的设置里有一页「Realheart」，和观测页**同一套分区**。

- **左边目录、右边内容**，九个分区一眼扫完；窗口窄了自动收成下拉
- **默认只读**，点「编辑」才能改；每项下面一行灰字说是干什么的，`?` 悬停出完整来历
- 按名字 / 说明 / 键名**搜**，命中的区自动展开
- 改完了点保存，**先给你看一遍改动清单**（`pingMinMinutes：30 → 45`），确认才写
- 危险项（关总开关、清空能力配方、注入预算降到 1000 以下）会**单独再问一次**
- 编号的段名（24 个注入段）是**勾选**的，不用手打；JSON 字段有「校验」按钮当场 parse
- 每一项旁边有「重置」，改回默认值

写进 profile 的 `cordis.patch.yml`，插件热重载；观测页面板上那份写 `config.user.json`，改完要重启。
**两处都能改，别同时改同一项** —— 面板那份优先。

## 长会话不会越聊越贵

这条是**用钱量出来的**。

注入会往系统提示词里写「现在几点」「这一轮跑了多久」。听起来无害，但系统提示词是请求的最前面 ——
里面任何一个字符变了，**它后面的全部 token 都要重算**：剩下的注入段，以及你那十几万 token 的历史。

实测：两个真实会话，209 步里 31 次全量 miss、47 步里 18 次，**合计浪费 943 万 token**，
命中率掉到 81.6% / 62.1%（本来能到 98%）。

改法不是"把时间写粗一点"（那只是拿信息换钱），而是**换通道**：会随时间变的那几段
改成每一步**追加到消息末尾**，跟 dsh 自己那条 `Time sampled while preparing…` 同一个位置。
追加在尾部不碰前缀，缓存照常命中，**精度原样保留**（分钟级）。

改完实测：干净轮 **98.6% / 98.7%**，`cacheRead` 稳定在 6.8–7.1 万。

0.6.2 又搬走一个：**「距你上一次开口多久」**。它读的是 `last-inject.md` 的 mtime，
而那份文件每次装配之后都写（doctor 和调试页靠它看「她那一轮看到了什么」）。于是同一轮里：
第 1 步读到上一轮 → 说「4 天前」（这一段出现）；写完 mtime 变成「刚才」→ 第 2 步说空（这一段消失）。
**每轮自我删增两次。** 一个 58 步的会话里，第 2 步就这么 0% 命中、白烧 31.8K。

还留了个报警器：每次装配比对各段内容的指纹，谁在中间改了东西，
日志里当场点名「这几段打碎了前缀缓存」。上面那些数字就是它抓出来的。
同一轮里同一段变两次也单独报警 —— 【时间感】以前就藏在这种「出现又消失」里。

⚠️ 判据别记错：**system prompt 里没有「便宜的段」。** 排最后 ≠ 便宜 ——
它省下的只是系统提示词剩余那几十 token，你的历史一个字节都没省。
真正免费的只有消息末尾那条追加通道。

## 坏了怎么办

**先跑这一条**，它多数时候直接告诉你哪坏了、怎么修：

```bash
npx realheart doctor
```

它查：依赖 / 配置合不合法 / 账本能不能写 / 有没有坏行 / 注入今天有没有成功 / 有没有少过段 /
事件源三路还通不通 / **它还在不在线**。

**每一项不是 ok 的都带 `→` 怎么修。** 有 FAIL 时退出码非零，脚本里能直接用。

常见三件：

| 症状 | 大概率是 |
|---|---|
| 装完重启，一点反应都没有，日志里找不到「已注册」 | 包名没进 `dsh.profile.bundles` |
| 页面能开，但注入里没有状态那一段 | `injectMood` 关了，或这一轮被预算裁掉了 —— 翻 `last-inject.md` |
| **它不理人** | 先分是「不想说话」还是「没上线」：`doctor \| grep 在线` |

## 它不做什么

- **不注入人格。** 人格是你的事。别人往 `AGENTS.md` 里塞的人格如果让它做危险的事，那份人格负责。
- **不保证更像人。** 它只保证每一笔都有文件可查。
- **不动它的判断。** 什么时候记、记什么、说不说 —— 全是它自己的事。
- **不替你省钱。** 每轮多几十到几百字的注入，就是 cost。

## 配套（可选）

装了 QQ 通道（比如 `dsh-napcat`）之后，观测页会多一块「配套工具」，那里挂着给它配的小工具：

- **`napcat-rescue`** —— 掉线时的扫码抢救页。不用 SSH 上去，在几万行日志里翻那个两分钟就过期的二维码
- **`say`** —— 一条命令让它以自己身份发消息。自由时间里想说什么，不用等谁先开口

**没装那个通道就看不到这些。** 用不上的东西不往那儿摆。

## 这一版的状态

`0.5.x`，还在改。接口会变，行为还有坑。

每次改了什么、为什么、怎么退，`CHANGELOG.md` 里都有记录 —— **只记三件事：行为变了 / 装的步骤变了 / 数据格式变了。**

数据格式变的那一版会同时给迁移脚本。只改格式不给迁移，等于让人重装。

### 已知限制

- **Windows 桌面端的短唤醒 / 自由时间用不了。**
  桌面端 profile 被 Electron 独占，`dsh --profile desktop …` 会被直接拒
  （`profile "desktop" is managed exclusively by the Electron application`），
  而插件没有别的入口能让它"醒来"。Linux / 云端那台正常。桌面端会跳过并记一行说明，不刷错误。
- **短唤醒在桌面端还有一层**：Windows 上 dsh 是 `dsh.cmd`，Node 20.12+ 禁止直接 spawn `.cmd`。
  已经改成走 `DeepSeek Harness.exe + cli.js`（dsh.cmd 内部那一行），但上面那条 profile 限制绕不过去。
- 每轮多几十到几百字的注入，就是 cost。长会话那条优化让它别再多烧一遍历史。
